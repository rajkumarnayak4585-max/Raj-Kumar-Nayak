Aap `README.md` aur `index.html` file banana chahte ho? Neeche dono files ka code diya hai.

### 1. `README.md`

markdown
```

# My Website

Welcome to my website project!

## About
This project is a simple website created using HTML and CSS.

## Files
- `index.html` - Main webpage of the website.
- `README.md` - Project information and instructions.

## How to Run
Open the `index.html` file in your web browser.
```

### 2. `index.html`

html
```

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>
<body>
    <h1>Welcome to My Website!</h1>
    <p>This is my first website using HTML.</p>
</body>
</html>
```

### Files kaise banayein?

1. VS Code open karo.
2. Ek folder banao, jaise `my-website`.
3. Us folder mein `README.md` aur `index.html` naam ki do files banao.
4. Upar diya gaya code respective files mein paste karo.
5. `index.html` ko browser mein open karo.
